## Summary

Remove the hard BLOCKED gate that forces `master-report.md` to exist before the
`ava-tobe-orchestrator` (trigger `SD`) can proceed. The file is a consolidated summary
artifact produced at the end of AS-IS; its absence does not indicate an incomplete
diagnostic when the essential AS-IS artifacts are present. The gate is downgraded to a
non-blocking `[AVISO]` warning with a suggestion to generate the report. A fallback hard
gate is introduced for the case where **all** essential AS-IS artifacts are absent.

**Affected file**: `src/modules/ava-fabric-agents/tobe-architecture/agents/orchestrator-tobe.md`  
**Version bump**: `2.4.1` -> `2.4.2` (PATCH -- bug fix in agent instructions)
