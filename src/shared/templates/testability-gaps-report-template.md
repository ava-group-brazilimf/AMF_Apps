## Next Steps

### If Status = BLOCKED ❌

1. **Schedule architecture review meeting** with stakeholders identified in ADRs
2. **Update ADRs** to address blockers (run `ava-adr-tobe` if decisions need revision)
3. **Re-run architecture design** (`ava-tobe-orchestrator` trigger `AD`)
4. **Re-validate testability** (re-run this agent after architecture updates)

**Do NOT proceed to codegen** until all blockers are resolved.

### If Status = CONDITIONAL ⚠️

1. **Document risk acceptance** in `project-config.yaml` → `signoffs.testability_warnings_accepted: true`
2. **Create technical debt items** in backlog for each warning
3. **Proceed to codegen** with awareness of reduced testability in flagged areas
4. **Plan refactoring wave** after initial implementation to address warnings

### If Status = PASS ✅

1. **Proceed to F3 (Codegen)** — architecture is testability-ready
2. **Include checklist** in code review process (verify implementation follows design)
3. **Monitor test coverage** during implementation (target: >97% line coverage)
